## Download

Download the latest version from [GitHub Releases](https://github.com/Manhhao/Hoshi-Reader-Desktop/releases/latest).

Requires macOS 15 or newer on Apple Silicon, or Windows 10/11.

## Development

### Prerequisites

- [Rust](https://rustup.rs/) 1.88+
- [Node.js](https://nodejs.org/) 22.12+
- [pnpm](https://pnpm.io/)
- [CMake](https://cmake.org/) 3.24+
- A C++23 compiler
  - macOS: Xcode Command Line Tools
  - Windows: Visual Studio with *Desktop development with C++ workload* and *C++ Clang tools for Windows*

### Run

```sh
pnpm install
pnpm tauri dev
```
